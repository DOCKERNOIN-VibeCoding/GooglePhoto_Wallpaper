# OAuth 클라이언트 발급 가이드

> **먼저 확인하세요: 대부분은 이 문서가 필요 없습니다.**
>
> 기본 방식인 **공유 앨범**을 쓴다면 Google 로그인도, Cloud 프로젝트도, 이 문서의 어떤 단계도
> 필요 없습니다. 앨범 공유 링크만 설정창에 붙여넣으면 끝입니다. 게다가 그쪽만 앨범 자동
> 동기화가 됩니다.
>
> 이 문서는 **Google Photos 피커**(공식 API로 사진을 직접 골라 담는 방식)를 쓸 때만
> 필요합니다. 피커는 자동 동기화가 되지 않습니다.

이 프로그램에는 자격증명이 들어 있지 않습니다. 그래서 처음 한 번, 본인 명의의 OAuth 클라이언트를
만들어 등록해야 합니다. 5분 정도 걸리고, 한 번 하면 다시 할 일은 없습니다.

> **이건 구글 계정 비밀번호와 무관합니다.** "이 프로그램이 내 Google Photos에 접근해도 된다"는
> 것을 Google에 등록하는 절차이고, 발급물은 `client_secret.json`이라는 파일 하나입니다.

---

## 1. Google Cloud 프로젝트 만들기

1. <https://console.cloud.google.com/projectcreate> 접속
2. 프로젝트 이름에 아무거나 (예: `Photo Wallpaper`) 입력하고 **만들기**
3. 생성이 끝나면 화면 위쪽에서 그 프로젝트가 선택되어 있는지 확인

## 2. Photos Picker API 켜기

1. <https://console.cloud.google.com/apis/library/photospicker.googleapis.com> 접속
2. **사용** 버튼 클릭

> 여기서 켜는 건 **Photos Picker API**입니다. 이름이 비슷한 "Photos Library API"가 아닙니다.

## 3. OAuth 동의 화면 설정

1. <https://console.cloud.google.com/auth/overview> 접속 → **시작하기**
2. 앱 이름: 아무거나 (예: `Photo Wallpaper`) / 사용자 지원 이메일: 본인 메일
3. 대상(Audience): **외부(External)** 선택
4. 연락처 이메일 입력 후 저장

### 3-1. 본인을 테스트 사용자로 추가

**대상(Audience)** 화면 → **테스트 사용자** → **Add users** → 본인 Gmail 주소 추가.

**여기까지만 하면 바로 쓸 수 있습니다.** 4번으로 넘어가세요.

---

## 3-2. (선택) 게시 상태에 대해

**대상(Audience)** 화면의 **앱 게시** 버튼은 아마 눌리지 않을 겁니다.
"유효한 앱 이름, 지원 이메일, 홈페이지 URL, 개인정보처리방침 URL이 필요합니다"라고 나옵니다.
**그대로 두셔도 됩니다.** 이유는 아래와 같습니다.

테스트 상태에서 Google이 발급하는 refresh token은 7일 뒤 만료됩니다. 다만 이 프로그램에서
토큰이 필요한 순간은 **사진을 새로 고를 때뿐입니다.**

| 동작 | 토큰 필요? |
|---|---|
| 배경화면 순환 (평소 동작) | ❌ 로컬 캐시만 읽음. 인터넷도 불필요 |
| 새 사진 선택 | ✅ 필요 |

그리고 사진 선택은 어차피 브라우저로 이동하는 작업입니다. 토큰이 만료된 상태에서
`Google Photos에서 사진 선택`을 누르면, 프로그램이 알아서 로그인 화면을 먼저 띄우고
그다음 사진 선택 화면으로 넘어갑니다. 오류도 뜨지 않고 별도 조작도 없습니다.

즉 **7일 만료의 실제 영향은 "가끔 사진 고를 때 로그인 화면이 한 번 더 뜨는 것"** 이 전부입니다.

그래도 만료 자체를 없애고 싶다면 선택지는 두 가지입니다.

<details>
<summary><b>방법 A: 내부(Internal)로 설정</b> — Google Workspace 조직 계정이 있는 경우</summary>

**대상(Audience)** 화면의 **내부로 설정** 버튼을 누르면 됩니다.
홈페이지 URL이나 개인정보처리방침 URL이 필요 없고, refresh token도 만료되지 않으며,
검증 절차도 없습니다.

**단, 그 Workspace 조직에 속한 계정만 로그인할 수 있습니다.**
배경화면으로 쓸 사진이 개인 Gmail 계정에 있다면 이 방법은 쓸 수 없습니다.
조직 계정(예: `you@yourcompany.com`)의 Google Photos를 쓸 때만 유효합니다.

버튼이 아예 보이지 않는다면 그 프로젝트는 Workspace 조직 소속이 아니므로 이 방법은 불가능합니다.
</details>

<details>
<summary><b>방법 B: 외부 프로덕션으로 게시</b> — 소유한 도메인이 있는 경우</summary>

**브랜딩** 페이지에서 다음을 모두 채워야 합니다.

- 앱 이름, 지원 이메일, 로고
- **애플리케이션 홈페이지 URL**
- **개인정보처리방침 URL**

두 URL은 **본인이 소유하고 Google Search Console에서 소유 인증을 마친 도메인**에 있어야
합니다. Google은 홈페이지·개인정보처리방침·승인된 도메인이 모두 같은 소유자로 추적되는지
확인합니다. GitHub 저장소 주소 같은 남의 도메인 URL은 통과하지 못합니다.

개인 프로젝트 하나 때문에 도메인을 준비할 필요는 없다고 봅니다. 이미 도메인이 있고
간단한 소개 페이지와 개인정보처리방침 페이지를 올릴 수 있는 경우에만 권합니다.
</details>

## 4. 클라이언트 만들고 JSON 내려받기

1. <https://console.cloud.google.com/auth/clients> 접속 → **클라이언트 만들기**
2. 애플리케이션 유형: **데스크톱 앱**
3. 이름: 아무거나 → **만들기**
4. 생성된 클라이언트 오른쪽 **JSON 다운로드** 클릭 → `client_secret_xxxxx.json` 저장

## 5. 프로그램에 등록

1. Google Photo Wallpaper 설정창 열기
2. **Google 연결에 쓸 OAuth 클라이언트** 항목의 **파일 선택**
3. 방금 받은 `client_secret_*.json` 선택
4. **Google Photos에서 사진 선택** 클릭 → 브라우저에서 로그인 및 권한 허용

등록한 파일은 `%LOCALAPPDATA%\GooglePhotoWallpaper\client_secret.json`으로 복사되므로,
원본은 옮기거나 지워도 됩니다.

> 로그인 도중 **"Google에서 확인하지 않은 앱입니다"** 경고가 나오면
> **고급 → (안전하지 않음) 계속** 을 누르세요. 본인이 방금 만든 클라이언트이므로 정상입니다.

## 사진 고르기

**Google Photos에서 사진 선택**을 누르면 브라우저에 Google 사진 선택 화면이 열립니다.

- 앨범 탭은 따로 보이지 않습니다. **검색창에 앨범 이름을 입력**하세요.
- 그 앨범의 사진들이 나오면 원하는 만큼 선택하고 **완료**를 누릅니다.
- 한 번에 최대 2000장.
- 동영상은 배경화면으로 쓸 수 없어 자동으로 제외됩니다.

사진은 선택 직후 전부 로컬로 내려받습니다(Google이 주는 링크가 1시간 뒤 만료되기 때문).
이후에는 인터넷 없이도 배경화면이 계속 돌아갑니다.

## 문제 해결

**"액세스 차단됨: 앱이 Google의 인증 절차를 완료하지 않았습니다"**
→ 3-1의 테스트 사용자 목록에 로그인하려는 계정이 없습니다. 그 계정을 추가하세요.

**"Google에서 확인하지 않은 앱입니다" 경고**
→ 정상입니다. **고급 → (안전하지 않음) 계속** 을 누르세요.

**"앱 게시" 버튼이 회색이라 눌리지 않음**
→ 정상이며 누를 필요도 없습니다. 위 3-2 참고.

**로그인 화면이 자꾸 다시 뜸 (일주일에 한 번꼴)**
→ 테스트 상태의 7일 만료입니다. 로그인만 하면 그대로 진행됩니다. 없애려면 3-2의 방법 A 또는 B.

**"refresh token을 받지 못했습니다"**
→ 이미 이 앱에 권한을 준 적이 있어서입니다.
<https://myaccount.google.com/permissions> 에서 해당 앱 권한을 삭제하고 다시 연결하세요.

**403 PERMISSION_DENIED**
→ 2단계의 **Photos Picker API**가 꺼져 있습니다.

**사진 다운로드가 실패함**
→ 선택 후 1시간이 지나면 Google이 주는 링크가 만료됩니다. 다시 선택하세요.
